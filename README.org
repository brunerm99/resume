#+title: Marshall Bruner's Resume

Typst resume. =main= holds the generic version; make a branch for a tailored copy.

* Compile
#+BEGIN_SRC bash
typst compile resume.typ
#+END_SRC

* Live preview
#+BEGIN_SRC bash
typst watch resume.typ
#+END_SRC
Then open =resume.pdf= in a viewer that reloads on change (zathura, okular, evince all do).
Editor plugins (tinymist for VS Code / Zed / Neovim) give an inline preview instead.

* Fonts
Name uses IBM Plex Mono; icons use Font Awesome 6 (OTF files copied from TeX Live into
=~/.local/share/fonts/fontawesome6=). Body text is New Computer Modern, bundled with typst.

Editing notes are in the comment block at the top of =resume.typ=.
